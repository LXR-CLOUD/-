# 水声实时处理与发射机系统

## 1. 项目简介

本项目包含一套水声实时处理及发射机相关程序代码，主要由 FPGA 实时处理程序、Qt 上位机软件以及 STM32 水声发射机程序三部分组成。

项目对相关软件及嵌入式程序进行分类整理，方便代码管理、版本维护和后续开发。

## 2. 项目组成

本项目主要包含以下三个部分：

### 2.1 FPGA 实时处理程序

文件：`FPGA实时处理程序代码.rar`

主要内容：
- FPGA 实时处理相关程序代码。
- 用于 FPGA 硬件平台的逻辑处理与实时运算。
- 具体功能及开发环境以压缩包内源码为准。

### 2.2 Qt 上位机软件

文件：`Qt上位机软件代码.rar`

主要内容：
- 基于 Qt 框架开发的上位机软件代码。
- 用于上位机软件界面及相关功能开发。
- 具体通信协议、界面功能及运行方式以源码为准。

### 2.3 STM32 水声发射机程序

文件：`STM32水声发射机程序代码.rar`

主要内容：
- 基于 STM32 平台的水声发射机程序代码。
- 用于嵌入式控制程序开发。
- 具体硬件接口及控制功能以源码为准。

## 4. 开发环境

项目涉及不同的开发平台，具体环境如下：

| 项目模块 | 开发平台 | 开发环境 |
|---|---|---|
| FPGA 实时处理 | FPGA | zynq7035 |
| Qt 上位机软件 | PC | Qt Creator / Qt |
| STM32 水声发射机 | STM32 | STM32L031F4P6 |


## 5. 使用说明

1. 根据需要下载对应的 `.rar` 压缩包。
2. 使用 WinRAR 或 7-Zip 解压文件。
3. 根据各模块的开发环境打开相应工程。
4. 配置对应的开发工具、硬件平台及相关依赖。
5. 根据实际硬件环境进行编译、下载和调试。
